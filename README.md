# Sofia - Bot de Estudos Inteligente (n8n)

A **Sofia** é um bot de estudos avançado para Telegram, construído sobre o n8n e alimentado pelo modelo multimodal **Gemma 4 31B IT**. Ela foi projetada para ser uma tutora acadêmica em Tecnologia e Engenharia.

## 🚀 Funcionalidades

- **Processamento Multimodal**: Sofia lê e entende tanto textos quanto imagens (fotos ou arquivos).
- **IA de Ponta**: Utiliza o modelo Gemma 4 para fornecer respostas precisas e didáticas.
- **Contexto de Conversa**: Memória persistente baseada no ID do chat do Telegram.
- **Raciocínio Didático**: Explicações detalhadas, passo a passo, e aplicação de normas ABNT.
- **Análise de Código**: Capacidade de explicar algoritmos linha a linha.

## 🛠️ Como Instalar

1.  Tenha uma instância do **n8n** instalada.
2.  Importe o arquivo `sofia_bot_github.json`.
3.  Configure as credenciais:
    - **Telegram API**: Crie um bot no [@BotFather](https://t.me/botfather).
    - **Google Gemini API**: Obtenha sua chave no [Google AI Studio](https://aistudio.google.com/).
4.  Ative o workflow.

## 📁 Estrutura do Repositório
